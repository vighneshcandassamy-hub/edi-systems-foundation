2. Register the expected measurement source/epoch in C1. 3. 5. `assess-get-forecast`, `assess-get-comparison` and `assess-query comparison` expose registration, missingness, scores, source coverage and caveats. A small error is not independent proof of the model or EDI advantage. Uncertain/censored/unavailable data remain explicit and no ordinary scalar score is fabricated.
6. Future authored review/finding requests can use the generated schemas to preserve causes/rivals/tests/uncertainty/affected targets. Optional `assess-submit` stages candidate-only C3 changes; no C3 acceptance, C0 notification or C7 adoption is implied. C4 may query assessments and request a descriptive inquiry review; no model inference was connected or run by C6.

All steps are future usage instructions. No Runtime/store, registration, measurement capture, scan, score, model update, simulation or product test ran while creating these templates.
