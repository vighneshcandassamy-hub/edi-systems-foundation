# Operator entry point

The owner folder contains private world/state and audit/evaluation material. It is not a participant image or a public redistribution package.

| Responsibility | Material |
| --- | --- |
| Mission and generic operations | [participant/](../participant/) and canonical files in environment/v0_2 |
| World execution/configuration | [active world](../environment/v0_2/), [fixture manifest](../environment/v0_2/fixture/manifest.json) |
| Attribution and storage | [metadata/](../metadata/), [coverage](../docs/COVERAGE.md) |
| Scientific gap review | [interlude audit](../operator-audit/README.md), current world README |
| Outcome accounting | [evaluate.py](../environment/v0_2/evaluate.py), operator-only |
| Engineering evidence | [reports/](../environment/v0_2/reports/), retaining scoped self-review status |
| Next planning decisions | [handoff](../TESTING_HANDOFF.md) |

Supply only the four allowlisted starting files and the public endpoint/token after arranging isolation. Further observations travel through public operations. Do not mount the owner repository, private state, world transitions, audit or run database into the participant.

Initially withheld records, new measurements, genuine gaps and permanently private truth are different. Return grounded source information or explicit unavailability, without creating missing facts to support a hypothesis.

Consolidation does not start the broker, advance the world, send messages to people or approve revised objectives. Tokens, model credentials and run journals stay outside Git.
