# ADR-011: compose existing native components before integrated testing

Status: implemented in source; runtime unverified. Date: 22 October 2026.
Baseline: 9b275da82e69cd0b77b7d63525067721017a165c.

The architecture already allocates C0-C7 and fixed student/selective teacher roles.
The autonomous controller exposed only a subset of native operations and did not
feed all results back to reasoning. A paid-only teacher dependency was incompatible
with the owner's $0 setup. A known native rejection was indistinguishable from
pending controller work.

Compose the existing owners with one application profile and a finite C0 component
operation catalogue. Reuse Workflow's native router and request validators. Expose
argument schemas on demand. Return attributed native results to subsequent selected
context; retain model candidates through existing C3 ports. Supply the existing
selective teacher role with explicit file export/import, same-cut critique and
student revision, without claiming an automatic subscription API or weight training.
Retain definite rejected outputs under C4 and allow a bounded new correction job;
unknown provider completion never authorizes an automatic resend.

Alternatives rejected for this scope: start another benchmark before the wiring is
finished; introduce a new agent framework/store; let a model mutate other owners'
state or adopt policy; silently repair scientific content; require paid teacher
inference; invent a trainer contrary to the initially fixed-weight design.

Existing authority, eight logical owners, nine representation families and the
frozen benchmark are preserved. No additional domain-solving algorithm is added.
Fresh workspaces are required for the new episode contract. File feedback has
operator-declared identity/usage and requires explicit import; it is a deliberate
manual transport, not an autonomous hosted teacher service. Numerical, scientific,
isolation and runtime claims remain subject to later verification.

The owner explicitly deferred model/product tests until this build is complete.
