# ADR-001 — Separate Meadows-based EDI foundation repository

Status: accepted for repository organization by the owner's request, 20 October 2026.

## Problem and decision

The current seven-chapter system-of-systems architecture and appendix semantic foundation need an identifiable home for the next EDI iteration. Store them in a new private personal repository named `edi-systems-foundation`, alongside retained component plans and review skills.

Use version `0.1.0-architecture` for this repository baseline. Preserve the source documents' own v0.7/v1.0 versions. The repository version denotes a design snapshot, not a newly qualified executable EDI.

## Rationale and consequences

The integrated model and semantic reference provide the current conceptual authority. Earlier component snapshots remain useful context, with a required reconciliation before implementation. Existing research and experimental claims remain attributed to their original repository and evidence.

The owner authorized storing this new version on the personal GitHub account. This does not authorize public disclosure, new credentials, paid inference or modifying the older repository.

## Verification

Check imported hashes, source allocations, requirement and case identities, the master graph, local links and secret patterns. Verify the created repository owner, private visibility and exact remote content after upload. Authentication and remote completion remain separate from local preparation.
