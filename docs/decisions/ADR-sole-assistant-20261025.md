# ADR — Sole current-assistant reasoning model

Date: 25 October 2026. Status: implemented transport; runtime qualification pending.
Base source: 6ca72f16c346add1c777da2cb57ea65406d0766c.

The owner replaced the Qwen student / teacher arrangement with the current assistant as the single EDI reasoning model. This supersedes the proposed 12-student-call repair/comparison batch. It does not authorize a paid API or claim an unattended subscription integration.

C4 exports an immutable evidence cut, source references, available operations, protocol questions and native response schema. The current assistant returns a proposal through explicit file import. C4 retains raw generated bytes and validates the proposal; C0 schedules the selected operation; C3 controls representation admission; C7 and the broker retain access/action authority. C1 observations and C2/C5/C6 capabilities remain available through existing native operations. No teacher, Qwen service, model training or automatic background assistant call is configured.

`StudentConnection.mode=file-exchange` selects the sole-reasoner transport. `teacher.mode=disabled`, selective nonteaching scheduling and `use_teaching_memory=false` are mandatory. The internal `student`/`standard` names are retained native API compatibility identifiers for the sole proposer slot; they do not create a student-teacher cycle. Historical code and failures remain preserved. The user-facing handoff is `waiting-reasoner` / `import_reasoner`.

The manual exchange cannot authenticate provider version or measure this assistant's actual token use or energy. Binding is explicitly operator-declared. Exported bytes are bounded separately from the existing exact-token vLLM admission path; no zero-count or estimated-token substitute is used. Unknown usage consumes the full native job reservation. This is an operational accounting allowance, not a measured cost or a guarantee of provider context limits.

A response may propose hypotheses, tests, candidates and one next operation. No operator rewrite of the selected action, invented evidence, bypass of reference checks, or direct world-model mutation is introduced. Repeated import is rejected; changed request bytes conflict; malformed outputs remain retained and use the existing bounded correction path. Cross-owner/native effects stay idempotent; expired runs are not migrated.

Qualification requires authored transport/error/reopen regressions and a fresh actual native run with this session supplying the reasoning. Fixture success is not reasoning success. Current assistant already knows the implementation and earlier attempts; independent isolation and comparative advantage are not established. General intelligence, neural learning and superiority remain unqualified.
