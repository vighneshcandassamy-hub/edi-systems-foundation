# ADR-005: bounded C2 derivations and candidate-only world proposals

20 October 2026 (UTC). Code 0.4.0. Input source revision `c43b8d5942b154e7849226208dd82f9d7736ca91`. Status: source implementation, unqualified. The owner requested C2 contingent on alignment of C3. C3's candidate/evidence/version interfaces support this bounded increment in source review; full C3 requirement satisfaction and runtime acceptance remain unestablished. No claim that the condition was empirically qualified is made.

Retain the eight-owner architecture and IF-02/08/14 operation directions. C2 reads C1, owns immutable derived artifacts and proposes candidates to C3. Only C3 decides canonical admission. C2 cannot alter source bytes, accept its own interpretation, grant action authority, or call C4 directly. C0 may supply scoped authored context; no new C2-C4 lane or unallocated full-world read is added.

Choose deterministic native decoders first: explicit UTF-8 text, lexeme-preserving JSON, string-preserving CSV, PNG IHDR metadata and supported WAV header metadata. Unknown formats remain native references. Do not require an LLM at intake/decoding or install every researched parser/model. Docling, FFmpeg, image/audio understanding, OCR, graph/music/array parsers, embeddings, entity-linkage models and learned assistance remain replaceable future adapters. C4's student/teacher reasoning plan is unchanged.

Keep raw evidence, decode results, operator/imported semantic annotations and canonical admission separate. Event/state/rate/pattern/structure/mechanism/purpose roles are orthogonal to evidential basis. Multiple tags require a rationale; unclassified is valid. Exact byte quotes can be checked; a paraphrase or a tag is not thereby verified. Cardinal quantities get a declared limited SI dimensional check, while original values/units are retained. No ordinal averaging, missing-to-zero conversion or implicit quantity conversion occurs. Pint remains a future wider arithmetic adapter; this small checker does not replace it generally.

Automatic association proposals are limited to matching registered source handles or whole-payload manifest hashes. They never imply physical identity or independent corroboration. Explicit referent/part/replacement hypotheses retain rationale, evidence, alternatives/contradictions and assistance lineage; no uncertain-link transitive closure or destructive merge occurs.

C2 uses its own lazily opened SQLite database, preserving native C1 availability when parsing/C2 storage/C3 storage is unavailable. Store a bounded immutable derivation and retry identity before world submission, then durably stage the exact proposed patch before calling C3. A C3 commit and a C2 final submission receipt are separate commit boundaries; retries reuse the staged original C3 request and resolve its original result even if the mapper later changes. Optional C3 consumed progress follows the existing C3 protocol; C0 alone may subsequently acknowledge C1.

Alternatives: parser outputs as new C1 observations would create evidence echoes; automatic semantic classification/physical merging would import unsupported claims; a universal multimodal model/service stack would add inference/operations before the consumer contract is ready; a shared writable database would weaken owner separation. Native feature statistics suffice for this initial retrieval representation; they are not semantic embeddings or an identity metric.

Bindings: existing Python/Pydantic/SQLite plus Python standard-library JSON, CSV, wave, struct, zlib and Decimal. No dependency installation, external inference, weights, network acquisition, deployment or benchmark. Primary references: [Python JSON](https://docs.python.org/3.14/library/json.html), [CSV](https://docs.python.org/3.14/library/csv.html), [wave](https://docs.python.org/3.14/library/wave.html), [PNG specification](https://www.w3.org/TR/png-3/), [BIPM SI units](https://www.bipm.org/en/measurement-units/si-base-units). These ground APIs/format/unit conventions; they do not validate this code's runtime behavior.

See [C2 runtime specification](../implementation/C2_INTERPRETATION_RUNTIME.md) for traceability, interfaces, bounds, source checks and open cases. Qualification remains deferred under the owner's structure-first instruction. Earlier source reviews and historical failures are preserved.
