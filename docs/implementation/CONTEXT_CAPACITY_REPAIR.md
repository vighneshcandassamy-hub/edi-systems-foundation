## Implemented correction

C4 now shares one context-construction function between read-only preview and native inquiry admission. Preview does not commit an episode, allocate a job, reserve inference tokens or call a model. The native gateway renders the same prospective student input and asks its configured exact tokenizer for the count. The preview job ID is a declared sizing placeholder, so C0 leaves headroom and every actual dispatch is still counted independently.

C0 journals the sizing result and chosen request before C4 freezes the inquiry. Its deterministic, domain-independent selection keeps the adopted mission and latest acquired evidence, defers older selections, then provisional lessons/world views, and narrows the latest textual range only when needed. Deferred IDs and narrowed ranges are explicit in context; original records remain available. No generated summary replaces the source. Forty preview attempts and the existing deadline bound planning. Intensive mode leaves 4,096 input tokens for stage growth; selective mode leaves 512. These margins are engineering assumptions, not guarantees that arbitrary later output will fit.

If the complete mission/access/protocol and minimum chosen evidence cannot fit, the controller yields a capacity error before allocating a model job. If later generated material exceeds the unchanged cap, the exact final check also yields capacity. It no longer presents that deterministic failure as a dependency wait. Unknown actual provider completion retains its original no-retry fence.

For a successful public read that already returns a complete native asset, C1 now verifies public document identity, offset, completeness, byte count and SHA256 before retaining decoded native bytes. C0 selects those native bytes and retains the original JSON envelope separately. It makes no extra broker request and does not infer a missing range. The existing native source binding is reused; a decoded representation is not independent evidence. C2 receives the selected native bytes through its existing interpretation port. Partial or unsupported sources remain explicit acquired material requiring further selected work.

The revision decoding grammar now requires the nonempty feedback_response already required by native admission. It does not require agreement with the teacher or prescribe the next action. This aligns output generation with validation; it does not solve the observed rationale-to-action inconsistency.
