# Single assistant reasoning connection

The current ChatGPT session is the sole reasoning model. EDI exports a native pending request; the assistant inspects that exported evidence and available operations, then returns a hypothesis/decision proposal. EDI performs validation, authorized execution, evidence retention and representation admission. Each completed operation returns through the next evidence cut. There is no teacher cycle or Qwen inference service on this path.

Configure the existing proposer connection with `mode: file-exchange`, a declared session binding, a private exchange directory, an explicit export byte budget and attribution. Disable the teacher and teaching memory. The active example is `examples/autonomous/assistant_run.py`; its exact evidence/run identities remain native C4/C0 identities.

Operational sequence:

1. Create a fresh authorized workspace and broker session. Do not migrate expired state.
2. `IntegratedApplication.step()` exports one request and returns `waiting-reasoner`.
3. Inspect that request's exact evidence, limitations, public/native operations and schema. Return only generated content fields; transport supplies identity. No world/evaluator reads outside EDI operations enter the reasoning.
4. Call `import_reasoner(job_id, response_path)` once. It retains generated bytes; the subsequent native step validates and schedules the proposal. Reopening the same pending or completed state does not invoke a model or replace an output.

Do not infer actual token use from export size. Missing usage is unknown and fully reserved by C0. Provider identity is declared, not independently authenticated. No background API, paid inference or subscription-token extraction is implemented. The notebook transports this session's proposals explicitly and keeps checkpoints at every pause.

Architecture/review: [decision](../decisions/ADR-sole-assistant-20261025.md). The existing C0–C7 owners remain. The teacher/student diagrams and results are historical configurations; this active arrangement has a single C4 reasoning model. Scientific-learning and comparative qualification require separate evidence.
