# Capability-by-capability development

1. Adopt the current architecture and appendix terminology as the working conceptual baseline, retaining its open questions.
2. Reconcile the Observe plan and observation–substrate handoff with those definitions. Preserve raw/source evidence, source identity uncertainty and temporal ownership.
3. Reconcile substrate functions and interfaces before selecting a concrete representation or implementation.
4. Specify one useful end-to-end vertical slice with explicit acceptance criteria, native inputs, budgets and failure/recovery behavior.
5. Implement and qualify that slice, then extend only where the next capability requires it.
6. Compare against strong alternatives after the integrated implementation works and the comparison protocol is frozen.

This is a proposed continuation order. No benchmark, paid job or deployment is launched by this repository import.
